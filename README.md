## what i do

**3D / Blender** — modelling with an eye for aesthetics over realism. if it looks right, it is right.

**Tiny Electronics** — aesthetic-first hardware. raspberry pi, esp32, whatever fits the vibe. the enclosure matters as much as the circuit.

**Video Editing** — pacing, colour, atmosphere. the craft underneath the content.

**Rust + WASM** — low-level image processing, desktop apps via Tauri. native performance, zero bloat.

<br>

## latest build

### ⚡ Image Booster V1
> ultra-lightweight WASM & native Rust imaging workstation

a real-time DSP tool for pixel manipulation and geometry transforms — compiled to a **1.2 MB `.exe`** via Tauri v2. no Electron, no runtime overhead. image filters, vector crop engine, contrast/saturation/sharpness controls, and a sine-wave feedback layer for good measure.

`Rust` `WebAssembly` `Tauri v2` `DSP` `Web Audio API`
